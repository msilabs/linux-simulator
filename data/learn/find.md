`find কোথায় শর্ত`। কোথায় থেকে খোঁজা শুরু হবে, আর কোন শর্তে মেলাবে।

## নাম দিয়ে

- `find ~ -name "*.jpg"`: home-এর ভেতরে সব `.jpg`।
- `-iname`: বড়-ছোট হাতের অক্ষর এক ধরে।

`*` থাকলে নাম quote-এ রাখুন, নাহলে shell আগেই বাড়িয়ে দেয়।

```terminal
$ find ~ -name "*.jpg"
$ find /var/log -name "*.log"
```

## ধরন দিয়ে

- `-type f`: শুধু ফাইল।
- `-type d`: শুধু ফোল্ডার।
- `-maxdepth 1`: বেশি গভীরে যায় না।

শর্ত একসাথে দেওয়া যায়: সবগুলো মিললে তবেই দেখায়।

```terminal
$ find ~ -type d
$ find ~/projects -type f -name "*.css"
```

## অনুমতি না থাকলে

`/` থেকে খুঁজলে কিছু ফোল্ডারে ঢোকার অনুমতি থাকে না, তখন `Permission denied` লাইন আসে। যেগুলো মিলেছে সেগুলো তবুও দেখায়।

```terminal
$ find / -name hosts   # /root-এ ঢুকতে পারবে না, তবু আউটপুট আসবে
```

নিজে চেষ্টা করুন: `backup.sh` কোথায় আছে খুঁজে বের করুন।
