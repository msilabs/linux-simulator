**terminal** হলো কম্পিউটারের এমন একটা জায়গা, যেখানে mouse দিয়ে click না করে লিখে লিখে কম্পিউটারকে কাজ দেওয়া হয়। আপনি একটা **command** লেখেন, Enter চাপেন, কম্পিউটার কাজটা করে ফল দেখায়।

## কেন শিখবেন

- **server চালানো:** প্রায় সব web server Linux-এ চলে, আর সেখানে কোনো mouse বা ছবির পর্দা (GUI) থাকে না। শুধু terminal।
- **দ্রুত কাজ:** একশোটা ফাইলের নাম বদলানো mouse দিয়ে আধা ঘণ্টা, terminal-এ এক লাইন।
- **developer-এর রোজকার কাজ:** `git`, `npm`, `composer`, `docker` সবই terminal-এ চলে।

## prompt পড়া

terminal কিছু লেখার জন্য অপেক্ষা করলে লাইনের শুরুতে একটা লেখা দেখায়। একে বলে **prompt**:

```
dev@laptop:~$
```

- `dev`: কোন user হিসেবে আছেন।
- `laptop`: কম্পিউটারের নাম।
- `~`: এখন কোন ফোল্ডারে আছেন। `~` মানে নিজের home ফোল্ডার।
- `$`: সাধারণ user। root (সব ক্ষমতার user) হলে এখানে `#` দেখায়।

## প্রথম command

নিচের বাক্সে আগে থেকে `whoami` আর `hostname` চালানো আছে। এরপর নিজে `date` লিখে Enter চাপুন।

```terminal
$ whoami
$ hostname
```

প্রতিটা command-এর পরে নীল রঙের বাক্সে বাংলায় বলা থাকে কী হলো। ভুল command দিলে লাল রঙে বলবে কী সমস্যা। যেমন `whoamii` লিখে দেখুন।

## কাজের key

- **Tab:** ফাইল বা command-এর নাম অর্ধেক লিখে Tab চাপলে বাকিটা নিজে পূরণ হয়।
- **↑ ↓:** আগে চালানো command আবার আনে।
- **Ctrl+L:** পর্দা পরিষ্কার করে। `clear` লিখলেও একই কাজ হয়।
