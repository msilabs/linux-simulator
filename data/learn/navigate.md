terminal সবসময় একটা ফোল্ডারের ভেতরে থাকে। file manager-এ যেমন একটা ফোল্ডার খোলা থাকে, ঠিক তেমন। তিনটা command দিয়ে চলাফেরা শুরু হয়।

## pwd: কোথায় আছি

`pwd` (print working directory) এখনকার ফোল্ডারের পুরো ঠিকানা দেখায়।

## ls: ভেতরে কী আছে

`ls` এখনকার ফোল্ডারের ফাইল আর ফোল্ডারের নাম দেখায়। কাজের দুটো option:

- `ls -l`: প্রতি লাইনে একটা, সাথে অধিকার, মালিক, আকার আর সময়।
- `ls -a`: `.` দিয়ে শুরু হওয়া লুকানো ফাইলও দেখায়, যেমন `.bashrc`।

option একসাথে লেখা যায়: `ls -la`।

```terminal
$ pwd
$ ls
$ ls -la
```

## cd: অন্য ফোল্ডারে যাওয়া

`cd` (change directory) দিয়ে অন্য ফোল্ডারে যাওয়া হয়।

- `cd projects`: এখনকার ফোল্ডারের ভেতরের `projects`-এ ঢোকে।
- `cd ..`: এক ধাপ উপরে ওঠে।
- `cd` বা `cd ~`: যেখানেই থাকুন, এক লাফে home-এ ফেরে।
- `cd -`: আগে যেখানে ছিলেন সেখানে ফেরে।

নিচের বাক্সে `projects/my-site`-এ ঢোকা আছে। prompt-এ `~/projects/my-site` দেখুন। এবার নিজে `cd ..` দিয়ে উপরে উঠুন, তারপর `cd` দিয়ে home-এ ফিরুন।

```terminal
$ cd projects/my-site
$ pwd
$ ls
```

`cd proj` লিখে Tab চাপুন, নাম নিজে পূরণ হবে। লম্বা নাম পুরো লিখতে হয় না।

## tree: পুরো গাছ একবারে

`tree` ফোল্ডারের ভেতরটা গাছের মতো দেখায়। `-L 2` মানে দুই স্তর পর্যন্ত।

```terminal
$ tree -L 2
```
