প্রতিটা command-এর দুটো আলাদা আউটপুট থাকে:

- **stdout:** স্বাভাবিক ফল।
- **stderr:** ভুলের বার্তা।

দুটোই সাধারণত পর্দায় আসে, কিন্তু আলাদা করে অন্য জায়গায় পাঠানো যায়।

## > আর >>

- `command > ফাইল`: ফল ফাইলে লেখে। আগের লেখা **মুছে যায়**।
- `command >> ফাইল`: আগের লেখা রেখে **শেষে যোগ** করে।

```terminal
$ echo "প্রথম লাইন" > log.txt
$ echo "দ্বিতীয় লাইন" >> log.txt
$ cat log.txt
$ echo "নতুন" > log.txt
$ cat log.txt
```

শেষের `>` আগের দুই লাইন মুছে দিয়েছে। রোজকার একটা ভুল এটা: যোগ করতে চেয়ে `>` লিখে পুরো ফাইল মুছে ফেলা।

## 2>: শুধু ভুলের বার্তা

`2>` শুধু stderr ফাইলে পাঠায়। ফল পর্দায় থাকে, ভুলগুলো আলাদা ফাইলে জমে।

```terminal
$ ls notes.txt nope 2> errors.txt   # nope নেই, ভুলটা ফাইলে যাবে
$ cat errors.txt
```

## < : ফাইল থেকে ইনপুট

উল্টো দিকে `<` ফাইলকে command-এর ইনপুট বানায়। `wc -l < notes.txt` শুধু সংখ্যা দেখায়, ফাইলের নাম না।

```terminal
$ wc -l < notes.txt
```
